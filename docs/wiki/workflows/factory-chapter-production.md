# 本地章节生产实验

入口 `/factory`。完整操作与启动说明见 [章节生产 MVP](../../factory-mvp.md)。

任务：固定设定与目标 → 分镜 → 正文 → 结构化审稿 → 最多两轮局部修复 → 原子提交正文与状态 → 下一章交接。

运行快照保存版本、审稿、修复预算和状态版本；数据库租约阻止重复执行。暂停不丢弃在途结果，失败恢复沿持久化阶段继续。正文未通过检查时无法提交；新增核心设定、伪造原文证据或不匹配的前态都会阻止提交。

模块边界及代码约定见 [factory 模块说明](../../../server/src/modules/novel/factory/README.md)。本入口仍是独立实验，不自动回灌正式小说资产。
