# 章节生产与 Gemini 网页版交接

## 边界与原因

章节生产实验页使用本地规划模型生成小剧本，正文可由 Gemini 网页版完成。网页版交接以保存的小剧本和完整写作指令为边界，避免正文网关故障阻断已完成的规划。

`writerMode=gemini_web` 表示外部写作；旧快照缺少此字段时沿用接口写作，以免读取数据时悄悄改变原任务行为。新建表单默认网页版，旧任务通过显式切换接口保存选择。该选择位于现有任务快照，无需数据库迁移。

## 状态与恢复

规划完成后保存 script、prompt，将阶段设为 draft、状态设为 paused。恢复接口拒绝没有正文的网页版 draft；运行器也在 draft 拦截接口生成，保证已有交接直接开始的下一章同样等待回填。

正文回填保存 manual 版本，并进入 paused/review。显式继续后规划模型审核正文；通过审核才提交故事状态。存在阻断问题则等待外部修改，不调用接口修复、不消耗自动修复次数。已有失败或暂停任务可切换写作方式，不删除版本、审稿记录或已提交状态。执行租约防止切换、回填与在途模型调用互相覆盖。

连续多章任务每次遇到待回填正文都会停止；回填审核后可以自动准备下一章，但不能绕过正文输入与状态提交。

## 导出契约

Markdown 写作包包含全部章节目标，以及已生成章节和下一章交接的保存指令。指令复用 Prompt Registry 的 factory.chapter.write 模板，包含固定事实、禁止设定、状态、前章摘要、目标、场景、未来信息边界、风格与输出要求。导出和复制不调用模型、不提交状态。后续章节只有目标时不得伪造连续性状态或声称小剧本已生成。

本模块提供章节目标展示与小剧本生成，不提供主项目自动导演的全书规划能力。正文人工回填仅影响独立章节生产快照，不同步上游正式章节资产。
