# 章节生产 MVP

这是基于 AI-Novel-Writing-Assistant 的独立本地实验入口，用一章验证生产闭环。上游基线为 `2c035ac70f2639be46b9e77feb60028181bf7b65`，Gemini 网关固定为 `2bb988bfcbb82a7fab5d2c99aa5560ff40d64f7e`。

## 启动

使用 Node.js 22.12+ 和 pnpm 10.6+，在本目录运行：

```bash
pnpm install --frozen-lockfile
pnpm dev:factory
```

打开 http://127.0.0.1:5175/factory 。API 监听本机 8012，实验数据库和配置保存在 `.local-data/`。退出启动终端会停止子进程。目录中的旧研究工作台不受影响。

当前电脑已准备独立 Node 22 运行时，启动脚本会优先使用它。也可用 `FACTORY_NODE_BIN` 指定 Node 路径。切换 Node 主版本后需重新安装或编译 `better-sqlite3`，避免原生模块 ABI 不一致。

## 模型配置

可选本地 Gemini 网关：

```bash
bash scripts/setup-gemini.sh
bash scripts/start-gemini.sh
```

网关监听本机 8081；首次安装需要 Git、Python 3 和网络。在应用「模型设置」增加自定义厂商，URL 填 `http://127.0.0.1:8081/v1`，鉴权选无，模型选项已加入 `gemini-3.8-flash`；本地网关将它映射到网页版 Fast 档，实际模型版本取决于上游账户与页面发布状态，不能像官方 API 一样锁定 3.8。需要锁定版本时使用官方 Gemini API 的 `gemini-3.8-flash`。当前电脑已保存「Gemini 本地网关」配置。

章节表单分别选择正文模型与规划/审核模型。规划和审核需要可靠的结构化输出，可配置自己已有的 API；也可以先选择网关测试，但应人工检查审稿质量。模型列表连通只代表配置可读取，真实生成仍需实际试写验证。

macOS 也可在「模型设置」连接 ChatGPT Plus / Pro：点击连接后在系统浏览器登录并允许方案使用，再从账号提供的模型列表中选择模型。该连接只支持文本生成，温度和输出长度由 ChatGPT 服务决定；登录凭据使用 macOS 钥匙串保护。此功能需要 Node.js 22.12+，并使用 OpenAI 官方 Sign in with ChatGPT DevKit；该 DevKit 当前仅许可个人非商业用途。

## 使用

1. 填写固定设定、禁用设定、写作风格、初始状态，以及一至十个章节目标。固定事实和状态键不得冲突。
2. 选择单章运行或连续三章。每章依次产生分镜、正文和含七项检查的审稿结果。
3. 未通过审稿时最多局部修复两轮。仍未通过则阻塞，查看问题后人工修改正文，再恢复审核。
4. 通过审核才一起保存定稿和故事状态；下一章从已提交状态、上一章摘要和目标生成交接分镜。
5. TXT 仅导出已提交正文；JSON 包含任务、版本、审稿、状态和交接记录。

暂停会等待当前模型请求返回并保存结果，再停止后续步骤。崩溃或请求失败后可续跑；修复次数不会因重启重置。定稿后的交接失败只重试交接，不重写已提交章节。用量缺失时显示未知，不估造费用。

## 网关流式兼容修复

网关先获取并检查完整上游回复，再按 SSE 格式交给应用，因此本地网关的首段输出会等待本次生成完成。上游 HTTP 错误和空回复会以 502 返回，避免任务把空请求记为成功。运行 `.local/gemini-venv/bin/python scripts/test-gemini-patch.py` 可离线验证成功、空回复与上游拒绝三条分支。

## 网关请求降频

默认 OpenAI 兼容生成请求串行执行，每次完成后至少等待 30 秒再发下一次；网关启动后首次请求也等待 30 秒。上游报错或空回复会进入两分钟冷却，冷却期间立即返回提示，不访问 Google。冷却时间戳保存在 `.local-data/gemini-throttle.json`，重启不会清除。此措施用于验证请求频率的影响，不保证解决上游拒绝。

可在 `.local/gemini-web2api/config.json` 修改 `request_interval_sec`（默认 30）和 `failure_cooldown_sec`（默认 120），重启网关生效。上游单次尝试保持 `retry_attempts: 1`，避免一次应用调用产生密集重试。离线验证：`.local/gemini-venv/bin/python scripts/test-gemini-throttle.py`。

降频启用后的单次真实请求仍返回上游 HTTP 302，网关向应用返回 502；紧接着的重试约 3 毫秒返回冷却提示，未再次调用上游。六项离线测试通过，生成访问尚未恢复。
