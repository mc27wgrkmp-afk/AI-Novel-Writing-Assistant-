# Authoring boundary

Novel AI delivers outlines and chapter scripts. The author owns prose.

`assertAiProseGenerationAllowed` rejects chapter drafting, regeneration, automatic repair, and batch start/resume/retry before model calls or draft mutations. Manual editing, saved revision restoration, and read-only diagnosis remain separate capabilities. The director completes the selected script-planning scope, not the novel. Restart/watchdog recovery hands old prose jobs to the author without running them.

The boundary is deterministic product capability validation, not semantic routing. Do not implement a keyword bypass or expose a relabeled generation button as manual writing. Planned scene results must never be committed as factual story state before author-written prose exists.
