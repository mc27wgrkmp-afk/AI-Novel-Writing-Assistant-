# 章节剧本分批验收

本模块拥有章节剧本的三章批次状态、产物快照与人工验收。对外通过 `index.ts` 使用，内部不承担正文生成。

默认范围为全书目标章节数，首先交付 1–3 章；显式选择 4–9 章则交付 4–6 章。全书大纲与卷内章节列表可先准备，但任务单和场景卡只细化本批。失败和部分保存恢复沿用已保存的 `preparing` 范围。`waiting_acceptance` 时普通继续、强制恢复和通用审批不得推进，`all_accepted` 时不得重新执行。

剧本全部保存后写入 `chapter_script_batch_ready` 检查点。仅专用验收接口可按当前范围与 SHA-256 产物快照推进到下一批；最后一批验收后才写入 `workflow_completed`。范围上界同时保存在 `scopeEndOrder` 与 seed 的 `scriptBatchScope`，章节数使用所选范围长度。

快照包含已同步章节任务单、合法且非空的场景卡，以及活动规划版本中显示给作者的章节大纲和事件状态字段。正文内容与时间戳不参与快照。只读检查接口返回最新产物哈希，作者修改剧本后须重新读取、查看后提交。验收事务重读产物并比较哈希，再以 seed 与检查点做条件更新，阻止旧页面和重复请求跳过批次。先保存验收再排队准备下一批；排队失败可以恢复同一个已获授权的下一批。

用户正文、审核记录和既有规划结果不因批次切换清空；本模块不执行数据删除，也不启动正文流水线。
