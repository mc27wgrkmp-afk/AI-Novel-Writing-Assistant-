# 单章生产提示词边界

本目录只负责小剧本、正文、审核和局部补丁的模型合同。任务推进、最多两轮修复、状态提交、暂停和恢复属于 factory 应用层，提示词资产不自行重试；JSON repair 与 semantic retry 均为零，以避免隐藏调用突破章节修复预算。

运行时使用 `buildFactoryContextBlocks(input)` 作为 `contextBlocks`。六个必需组覆盖锁定设定、章节任务、连续性、未来信息边界、平台写法和作品风格，禁止摘要或静默丢弃。正文高级模板也必须保留这些组。`compileFactoryPrompt(input)` 返回默认正文资产的 System/Human 内容，适合交接和导出；实际调用仍应经过 Prompt Runner，以应用作品范围的 slots 与高级模板。

初始状态与当前状态分开呈现，当前已提交状态才是连续性依据。未来目标仅为计划，不是已发生事件或人物已知信息。小剧本必须逐字保留导入的必做项、禁做项和钩子，postValidate 在遗漏时拒绝输出。

审核必须返回全部七项检查。问题与状态变化的证据必须逐字存在于正文，变化的 `before` 必须与当前状态对应值一致；不存在的键使用 null。新的身份、规则、能力等必须标为 `new_canon`，由应用层决定暂停，不能提交为普通状态。模型推断本身不能证明一种变化安全，应用层仍需保护锁定键、验证变化和原子提交。

补丁最多八处，仅使用精确的 original/replacement 连续文本锚点。应用层必须验证锚点唯一且不重叠，禁止把整章重写作为局部补丁接受。

提示词管理目录的预览和受控测试接受完整 `FactoryPromptInput`；管理服务从该输入生成相同上下文块，不读取其他工作台小说来替换生产实验事实。
